## Amazon 리뷰 데이터 기반 아이템 협업 필터링(Item-based CF) 추천 시스템 구현 및 유사도 분석

### ○ 문제 정의
* 대규모 이커머스 환경에서 사용자의 과거 상호작용(평점) 데이터를 바탕으로 연관 상품을 추천("이 상품을 구매한 사용자가 함께 구매한 상품")하고 개인화된 Top-5 상품을 제안하는 **아이템 기반 이웃 협업 필터링(Item-based Collaborative Filtering)** 시스템을 구축함.
* 상품의 인기도(인기 상품 vs. 비인기 상품)와 유사도 측정 방식(Jaccard, Cosine, Pearson)에 따라 추천 품질과 데이터 희소성(Sparsity) 대응력이 어떻게 달라지는지 검증하고, 기존 협업 필터링의 한계(인기도 편향, 콜드 스타트 등)를 보완할 개선 방향을 도출하고자 함.

### ○ 역할
*(1인 프로젝트 / 알고리즘 구현 및 실험 분석 전담)*
* **추천 모델 및 유사도 지표 직접 구현**: Amazon 2014(Patio, Lawn and Garden) 5-core 데이터셋을 기반으로 Jaccard, Cosine, Pearson 유사도 계산 모듈과 사용자 평점 예측 기반 Top-5 개인화 추천 파이프라인을 라이브러리 의존 없이 직접 설계·구현.
* **인기도 구간별 비교 실험 및 메타데이터 교차 검증**: 인기 아이템과 비인기 아이템을 각각 선정하여 유사도 함수별 Top-5 유사 아이템 추천 결과를 도출하고, 상품 메타데이터와 대조해 추천의 맥락적 적절성과 각 유사도 지표의 장단점(평점 스케일 편향 보정 여부, 희소 데이터 민감도 등)을 분석.
* **타깃 사용자 개인화 추천 검증 및 개선안 도출**: 특정 사용자를 대상으로 유사도 지표별 Top-5 추천 결과를 비교·평가하고, 공통 평가 수 가중치, 인기도 패널티 부여, 메타데이터 결합 등 다각도의 알고리즘 고도화 방안을 제시.

### ○ 기술
* **Language & Library**: Python, PyTorch, NumPy, Pandas
* **Algorithm**: Item-based Collaborative Filtering, Similarity Metrics (Jaccard, Cosine, Pearson Correlation), Top-N Recommendation
* **Documentation**: LaTeX (실험 설계 및 정성·정량 분석 리포트 작성)

### ○ 결과
- **시간 가중치 적용을 통한 평점 정교화 및 실험군 추출**: 리뷰 작성 시점을 아이템별로 정규화하여 최신 리뷰일수록 높은 가중치를 부여하는 지표를 설계·적용함. 이를 통해 최신 선호도가 반영된 인기 아이템 상위 3개와 비인기 아이템 하위 3개를 선별하여 인기도 구간별 추천 성능 비교 기반을 마련함.
- **유사도 지표별 Top-5 연관 상품 도출 및 특성 검증**: 사용자 집합 연산 기반의 Jaccard 유사도와 사용자-아이템 평점 행렬 기반의 Cosine·Pearson 유사도 함수를 직접 구현하고, 전체 후보 아이템 간 유사도를 산출해 지표별 Top-5 추천 리스트를 도출함. 상품 메타데이터의 상품명과 매핑하여 단순 공동 구매 빈도(Jaccard)와 평점 크기·편차(Cosine, Pearson) 반영 방식에 따른 추천 성향 차이를 비교·분석함.
- **예측 왜곡을 방지한 개인화 추천 모델 및 정성 검증 파이프라인 완성**: 타깃 사용자가 평가하지 않은 후보 아이템에 대해 양의 유사도만 가중 합산하는 평점 예측 로직을 구현하여 음수 유사도 왜곡 및 0 나누기 오류를 방지하고 개인화 Top-5 상품을 도출함. 나아가 사용자의 과거 평가 이력과 상품 이미지 URL을 평점순으로 출력하는 마크다운 검증 도구를 구현해, 실제 구매 취향과 추천 결과 간의 맥락적 정합성을 직관적으로 평가할 수 있도록 고도화함.
